# **App Name**: WebStarter

## Core Features:

- React UI: A basic UI built with React and Next.js for the front-end, including reusable components and a responsive layout.
- NestJS API: A RESTful API built with NestJS for the back-end, providing endpoints for common web app functionalities.
- User Authentication: Authentication middleware is setup in NestJS
- Basic Template Generation: Use a generative AI tool to produce new, valid components or endpoints, for rapid scaffolding

## Style Guidelines:

- Primary color: Dark blue (#3F51B5) for a professional and calming feel.
- Background color: Light gray (#F5F5F5) to ensure content readability.
- Accent color: Indigo (#5C6BC0) to complement the primary color and create a unified theme.
- Body and headline font: 'Inter' for a clean, modern, neutral feel.
- A clean, intuitive layout that adapts to different screen sizes.
- Simple, line-based icons to maintain a modern and uncluttered aesthetic.
- Subtle transitions and animations to enhance user experience without being distracting.
